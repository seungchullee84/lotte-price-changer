# 롯데백화점 가격 변경기

Windows에서 롯데백화점 파트너포털의 상품 판매가 변경을 예약하는 로컬 도구입니다.

1. Windows에 Node.js 22 이상과 Google Chrome을 설치합니다. 엑셀 파일을 직접 불러오려면 Python 3도 설치하고 PATH에 추가합니다.
2. GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
3. **가격변경기 실행.cmd**를 더블클릭합니다. 처음 실행할 때 Playwright를 설치하고 Chrome에 변경기 화면을 엽니다. 터미널에서는 폴더 안에서 `npm install` 후 `npm start`로 실행할 수 있습니다.
4. **포털 열기**를 누릅니다. 상품등록기의 롯데 자동 로그인이 연결되어 있으면 저장한 계정으로 로그인합니다. **현재가 조회**에서 가격관리 화면을 엽니다.
5. 품번, 기준가, 변경가 순서로 목록을 붙여넣거나 엑셀을 불러옵니다. 적용 날짜와 시각을 선택한 뒤 **현재가 조회 → 변경 대상만 적용**을 누릅니다. **조회 후 바로 적용**은 목록을 조회하면서 가능한 상품을 이어서 저장합니다.

목록, 작업 기록, 전용 Chrome 프로필은 PC의 `data/` 폴더에 저장됩니다. 집 PC에서는 목록을 다시 불러오고 포털에 로그인합니다. 실행 중에는 터미널을 열어 두세요.

## 상품등록기에서 열기

상품등록기의 **가격변경기** 버튼과 연결하려면 이 저장소를 `%LOCALAPPDATA%\lotte-price-changer` 폴더에 별도로 설치합니다. 버튼은 기본 주소 `http://127.0.0.1:49428/`의 가격변경기를 새 탭에 엽니다. 실행 중이면 기존 서버를 사용하고, 꺼져 있으면 자동으로 실행합니다. 상품등록기에서 가격변경기를 열면 같은 PC에 암호화해 저장한 롯데 자동 로그인 설정을 연결합니다. 가격변경기의 **포털 열기**에서 해당 설정을 사용합니다.

## 가격 목록 보관

불러온 가격 목록은 업로드 시각·파일명·건수와 함께 PC에 보관합니다. **목록 관리**를 열어 보관된 자료를 불러오거나 TXT로 받을 수 있습니다. 보관 대상은 불러온 가격 데이터이며, 원래 Excel 파일 자체를 백업하는 기능은 아닙니다.

할인 적용과 원가격 복구에서 적용할 가격이 7,000원 이하인 상품은 **가격 조건 불일치**로 표시됩니다. 품번에 해당하는 포털 상품이 한 건이면 확인된 현재가로 진행합니다. GitHub에는 프로그램과 테스트만 올리며 `data/`의 목록·처리 기록·로그인 정보와 일회성 운영 스크립트는 제외합니다.

## 할인 판매가 직접 수정

표의 **할인 판매가**를 누르고 금액을 고친 뒤 **확인**을 누르면 현재 PC의 목록에 반영됩니다. 수정한 행은 **현재가 조회**를 다시 실행한 뒤 기존 **변경 대상만 적용**으로 처리합니다. 개별 행의 **포털 입력**은 입력 단계까지만 진행하므로 포털에서 내용을 확인하고 저장합니다. 포털에서 저장하거나 입력을 지운 뒤 다음 상품의 입력 버튼을 누르면 이전 입력 상태를 먼저 확인하고 진행합니다. 앞선 상품의 상태만 확인하려면 **입력 상태 확인**을 누릅니다. 선택한 적용 날짜와 시각을 그대로 사용하며, 이미 지난 시각으로는 실행하지 않습니다.

수정된 금액은 프로그램을 다시 실행해도 유지됩니다. 불러온 원문과 최초 보관 목록은 바뀌지 않아 TXT 다운로드로 원본 가격 데이터를 다시 받을 수 있습니다. 보관함에서 현재 사용 중인 목록을 다시 선택해도 수정 금액과 기존 조회·저장 결과를 유지합니다.

## 원가격 복구 예약

**가격 목록 → 원가격 복구**를 선택하고 **현재가 조회**를 누릅니다. 확인된 포털 상품의 복구 목표가는 목록의 원가격입니다. 날짜와 시각을 선택하고 **복구 대상만 예약**을 누릅니다. **조회 후 복구 예약**을 누르면 조회한 복구 대상에 선택한 시각을 바로 예약합니다. 이미 원가격이거나 다른 가격 변경이 진행 중인 상품은 조회 결과에서 확인할 수 있습니다.
